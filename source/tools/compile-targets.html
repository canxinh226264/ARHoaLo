Biên dịch ảnh mốc (MindAR)

Chỉ dùng khi chạy npm run dev. Trang này không được đưa lên web.

  1. Chọn ảnh theo đúng thứ tự trong src/config/artifacts.json (ảnh 1 = targetIndex 0).
  2. Bấm "Biên dịch", đợi thanh tiến trình chạy hết.
  3. Lưu file tải về vào public/markers/artifacts.mind, rồi npm run build.

Ảnh nên là file in chính thức, cạnh dài 800–1600 px, nhiều chi tiết, không bị loá.
